# Component List

## Industrial IoT Condition Monitoring System

| Component | Purpose |
|------------|---------|
| ESP32 DevKit | Main microcontroller |
| RS485 Module | Industrial communication interface |
| Temperature Sensor | Temperature monitoring |
| Current Sensor | Current measurement |
| Vibration Sensor | Equipment vibration monitoring |
| Power Supply | System power source |
| MQTT Broker | Telemetry communication |
| Node-RED | Dashboard visualization |

---

## Component Selection Criteria

Components are selected based on:

- Availability
- Communication support
- Industrial compatibility
- Cost effectiveness
- Development support
