# 1. Introduction

This project develops an Industrial IoT (IIoT) Condition Monitoring System using the ESP32. The system monitors industrial sensor data, publishes telemetry using MQTT, and visualizes real-time information on a dashboard.

---

# 2. Problem Statement

Industrial equipment requires continuous monitoring to detect abnormal operating conditions and reduce unexpected failures. Traditional manual monitoring is inefficient and lacks real-time visibility.

---

# 3. Objectives

- Develop modular ESP32 firmware.
- Read industrial sensor data.
- Publish telemetry using MQTT.
- Visualize data on a dashboard.
- Build an industry-standard embedded project.

---

# 4. Scope

The project includes:

- ESP32 Firmware
- MQTT Communication
- JSON Telemetry
- Node-RED Dashboard
- GitHub Documentation
