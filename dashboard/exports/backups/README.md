# Dashboard Backups

This directory contains project backup archives.

## Backup Contents

- Node-RED Flows
- Grafana Dashboards
- MQTT Configuration
- Project Settings

## Naming Convention

YYYY-MM-DD_Project_Backup.zip

Example

2026-08-02_IIOT_Backup.zip

## Backup Frequency

- Before major releases
- Before dashboard changes
- Before production deployment

## Restore

Extract the archive and import the required dashboard or flow into the respective application.
