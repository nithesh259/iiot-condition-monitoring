# ESP32 Pin Mapping

| Peripheral | ESP32 GPIO |
|------------|------------|
| Status LED | GPIO2 |
| RS485 TX | GPIO17 |
| RS485 RX | GPIO16 |
| Temperature Sensor | GPIO34 |
| Current Sensor | GPIO35 |
| Vibration Sensor | GPIO32 |

> Pin assignments may change depending on the final hardware configuration.
