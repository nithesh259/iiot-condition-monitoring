# Bill of Materials (BOM)

This directory contains the Bill of Materials (BOM) for the Industrial IoT Condition Monitoring System.

## Purpose

The BOM lists every hardware component required to build the project.

## Information Included

- Component Name
- Description
- Manufacturer
- Part Number
- Quantity
- Unit Price
- Total Cost
- Supplier

## Example Components

| Component | Quantity |
|-----------|---------:|
| ESP32 DevKit V1 | 1 |
| MAX485 RS485 Module | 1 |
| ADS1115 ADC Module | 1 |
| Temperature Sensor | 1 |
| Breadboard | 1 |
| Jumper Wires | As Required |
| USB Cable | 1 |

The BOM is maintained in `bill_of_materials.xlsx` and updated whenever hardware changes.
